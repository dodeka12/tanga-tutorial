# Changes since version 0.2.1

## New Features

- **New "Tables" tutorial (17 · Tables)** — documents the native, dependency-free
  `TableView` grid: typed columns (`number`/`string`/`bool`/enum/`column`/`custom`),
  keyboard navigation and sorting, backend-driven rows/columns, undo/redo, and
  JSON/CSV persistence with configurable delimiter/decimal separator.
- **Declarative control views** — the controls chapter now teaches the `*View`
  classes (`SliderView`/`DropdownView`/`ButtonView`/`TableView`/…) mounted with
  `set_layout`/`viz.add(view)`, plus the 2.0.0 display views
  (`LabelView`/`MarkdownView`/`LogView`/`SeparatorView`/`ToolbarView`) and menus
  (`MenuView`).
- **Expression `bind()`/`evaluate()`** — the expression tutorial documents the
  intent-specific evaluation entry points that narrow `__call__`'s return type.

## Breaking Changes

- **Controls tutorials rewritten for the removed `add_*` facades** — Viz 15, 16,
  and 19 no longer use `add_slider`/`add_button`/`add_control_group`/`add_menu`,
  the `control_position` anchor, or the runtime value API
  (`set_control_value`/`update_control`/`undo_table`/`redo_table`). They declare
  `*View` objects and mount them with `set_layout`/`viz.add(view)`, and update
  values with `view.set_value(...)`.

## Refactor

- **Renumbered visualization chapters** — inserted the new 17 · Tables chapter;
  banners & dialogs, responsive computation, export, and GA entities shifted to
  18–21 (folder/file names, `mkdocs.yml` nav, cross-references, and the README
  index updated to match).
- **Removed the SDF viewer tutorial** — the dedicated `SdfVisualizer` chapter
  (22 · SDF viewer) was dropped in favor of the standard viewer, which already
  renders SDF objects alongside mesh geometry (see 05 · SDF objects).
- **Live-viewer chapters note the lack of inline output** — the chapters that
  open a live viewer now state plainly that they render no static image in the
  docs, and carry a commented-out `viz.show(jupyter=False)` hint for opening a
  separate browser window.
