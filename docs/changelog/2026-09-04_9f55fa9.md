# Changes since version 0.2.0

## New Features

- **Visualization quick tour — CSG and scene-graph demos** — section 2 now adds
  the default axes/grid and composes a partially transparent mesh cylinder with a
  ray-marched `Composed` solid (sphere ∩ cylinder − cylinder); section 3 builds a
  three-segment chain by reusing one `Line` in two rotated `VizGroup`s.

## Bug Fixes

- **Visualization quick tour — section 1 framing** — the scene rendered tiny
  because an infinite `Line` (default 20-unit span) dominated the camera
  auto-fit, and `flush(fit_camera=True)` is a no-op for the serverless
  `display_snapshot()`. The line is now finite; the point sits outside the
  sphere and the line runs along the space diagonal.
- **Expression tutorial — inline math rendering** — the weighted-sum formula
  uses KaTeX and stream output is split into separate lines so the notebook
  displays correctly.
