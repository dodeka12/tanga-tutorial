# TanGA Tutorial

Tutorials for the [TanGA](https://github.com/dodeka12/tanga) geometric algebra
library.

This site walks through the **pytanga** Python package in two parts:

- **Visualization** — teaches the `pytanga.viz` viewer from scratch, no
  geometric-algebra background required.
- **Geometric Algebra** — covers the `Algebra` and `MV` types, the basis
  classes, the geometry submodule, and the numerical tooling.

## Visualization

Learn the `pytanga.viz` viewer from scratch — scenes, styling, cameras, labels,
interaction, animation, and export — with no geometric-algebra background
required.

**Start with the
[Visualization quick tour](tutorials/visualization/01_quick_tour/01_quick_tour.ipynb).**

## Geometric Algebra

Covers the `Algebra` and `MV` types, the eight basis classes, the geometry
submodule, and the numerical tooling (blade masks, the solver, matrix, tensor,
and expression).

**Start with the
[Algebra quick tour](tutorials/algebra/01_quick_tour/01_quick_tour.ipynb).**

## Running the tutorials

Each notebook page has **Open in Colab** and **Launch Binder** buttons at the
top, so you can run the cells without installing anything locally. See the
[repository README](https://github.com/dodeka12/tanga-tutorial) for local setup.
